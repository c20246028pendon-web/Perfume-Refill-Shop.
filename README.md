# LUIS | Perfume Refill Shop

## About the Project

LUIS Perfume Refill Shop is a responsive website designed to showcase perfume refill services and fragrance collections. It provides visitors with information about the shop, its services, available perfume collections, and contact details.

The website uses HTML, Tailwind CSS, JavaScript, and GSAP animations to create an attractive and interactive user experience.

## Features

- **Responsive Design** – Supports desktop, tablet, and mobile devices.
- **Home Section** – Introduces the LUIS Perfume Refill Shop.
- **About Section** – Provides information about the shop.
- **Services Section** – Showcases perfume refilling, custom fragrance, and bottle cleaning.
- **Products Section** – Displays Floral, Woody, and Fresh perfume collections.
- **Contact Section** – Shows shop contact information.
- **Dark Mode** – Allows users to switch between light and dark themes.
- **Mobile Navigation** – Provides a navigation menu for smaller screens.
- **GSAP Animations** – Adds smooth animations to website elements.
- **ScrollTrigger** – Animates sections and cards when scrolling.
- **Scroll Percentage Indicator** – Displays the current scrolling percentage.
- **Scroll Progress Bar** – Shows the user's reading progress at the top of the page.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/luis-perfume.git
```

### 2. Open the Project

Open the downloaded project folder using Visual Studio Code.

### 3. Run the Website

Open `index.html` using the VS Code Live Server extension or directly in your web browser.

## External Libraries

The website uses these CDN libraries:

- Tailwind CSS: https://cdn.tailwindcss.com
- GSAP: https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js
- GSAP ScrollTrigger: https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js

An internet connection is required to load these external libraries.

## Deployment

The website can be deployed using GitHub Pages.

1. Create a GitHub repository.
2. Upload the project files.
3. Open repository **Settings**.
4. Select **Pages**.
5. Under Build and Deployment, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Click **Save**.
